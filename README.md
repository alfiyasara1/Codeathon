# Codeathon
This Power BI assessment involved cleaning and transforming sales data by handling missing values, removing duplicates, and standardizing dates. I created interactive visualizations for regional orders, top 5 products, and profit trends. I also used DAX to create a calculated table, calculated column, and measure for deeper analysis.
 Documentation

**1. Data Cleaning:**  
Imported the sales dataset into Power BI using Power Query. Handled missing values, removed duplicate records, and standardized the `OrderDate` format. Numerical fields were cleaned and converted to the appropriate data type.

**2. Data Visualization:**  
Created a pie chart to show region-wise order distribution, a clustered column chart to display the top 5 products by order count, and a line chart to analyze profit trends over time.

**3. DAX Calculations:**  
Created the `EastRegionOrders` calculated table, `ProfitCostDifference` calculated column, and `TotalProfit` measure using DAX.

**4. Final Output:**  
The cleaned data and visualizations provide clear insights into regional orders, product performance, and profit trends.
